Build a fully dynamic and configurable Patient Registration Admin Module.

OBJECTIVE

The Patient Registration module should behave like a configurable workflow builder and dynamic form engine instead of a fixed registration screen.

The module must support multiple healthcare organization types including:

Small clinics
Welfare organizations
Corporate healthcare setups
Insurance-based organizations
NGOs
Large hospitals

The entire configuration should be managed from Admin without requiring development changes.

IMPORTANT STORAGE REQUIREMENT

All configuration data should initially be stored in local storage.

Changes made in Admin must immediately affect the:

Front Desk → Patient Registration Drawer → Register New Section

The front desk registration drawer should dynamically render fields, sections, workflows, and conditional logic based on the saved local storage configuration.

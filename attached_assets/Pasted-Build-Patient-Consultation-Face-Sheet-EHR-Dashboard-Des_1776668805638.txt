Build Patient Consultation Face Sheet (EHR Dashboard)

Design and implement a Patient Face Sheet page that opens when the user clicks on Consultation.

This page should function as an analytics-driven clinical dashboard showing a summarized view of patient health, history, and recent activity.

📌 1. Patient Header (Top Section)

Create a fixed top header with the following information:

Patient Image (avatar)
Full Name
MR Number
Date of Birth (DOB)
Gender
Phone Number
Address
Additional Highlights in Header:
Today’s Vitals (quick summary view)
History Taken By (with timestamp if available)
🚨 2. Critical / Chronic Conditions (High Priority UI)

If the patient has any previously diagnosed chronic or critical conditions, display them prominently at the top (above all sections).

Requirements:
Must be visually attention-grabbing (badge / alert strip / colored banner)
Always visible on page load (above the fold)
Fields:
Condition Name
Diagnosis Code
Severity (e.g., Critical)
Example:
Fever, Unspecified — R50.9 (Critical)
📊 3. Dashboard Behavior
Each section should display maximum 3 recent records
Include a “View All” or action icon for detailed view
Use card-based layout (grid system)

🎯 5. UX & Layout Guidelines
Use card-based UI with responsive grid
Keep critical condition alert at the very top
Maintain clean visual hierarchy (Header → Alert → Cards)
Ensure fast readability for doctors (scan-friendly UI)
Avoid clutter — prioritize summary over detail

A high-performance, doctor-friendly EHR dashboard where:

Critical conditions are instantly visible

Clinical data is structured and easy to navigate
